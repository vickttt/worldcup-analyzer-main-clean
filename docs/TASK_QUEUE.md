- 建立主剧本、次剧本、冷门剧本结构。

## P2 Path Consistency Score

- 检查推荐组合内部路径是否一致。
- 阻止明显冲突路径成为主推荐。

## P3 Portfolio Ranking 2.0

- 降低对 EV/ROI/Sharpe 的单点依赖。

## P4 My Portfolio Audit

- 对用户手动组合进行自动排名、结算和复盘。
- 将用户组合与系统推荐组合并列审计。

## P5 Team Intelligence Enhancement

- 增强球队信息、阵容、伤病、近期状态和赛后验证能力。
- 支撑推荐剧本和组合解释。
